# 规则清单

规则 ID 稳定不变，可以在 CI 或 Agent 工作流里按 ID 屏蔽或强制：

```bash
python -m shotlock deck.json --only SL003,SL008   # 只跑这两条
python -m shotlock deck.json --skip SL015         # 跳过这条
python -m shotlock deck.json --fail-on P1         # 有 P1 也返回非零
```

级别含义：

- **P0 阻断**——数据结构或物理上不成立，不修没法往下一环节走
- **P1 严重**——发布前必修，观众能看出来
- **P2 建议**——影响观感，按风格取舍

| ID | 级别 | 名称 | 抓什么 |
|---|---|---|---|
| SL001 | P0 | 结构完整性 | 必需字段缺失、id 重复、枚举取值非法、时长非正 |
| SL002 | P0 | 镜头时长边界 | 单镜短于 1.5s（剪不出来）或长于 25s（节奏垮） |
| SL003 | P0 | 台词语速 | 语速超过 7.5 字/秒，配音念不完；低于 2.2 字/秒听着拖（P2） |
| SL006 | P0 | 角色注册 | 镜头引用了角色表里没有的角色 |
| SL007 | P0 | 场景注册 | 镜头引用了场景表里没有的场景 |
| SL004 | P1 | 角色外貌漂移 | 镜头内的临时描述与角色表的发长、发色、服装色、年龄感互斥 |
| SL005 | P1 | 场景连续性 | 同一场景内时间或光线的 override 与场景表冲突，或中途无过渡跳变 |
| SL008 | P1 | 越轴检测 | 同一场景相邻镜头里双人画面左右位置整体对调 |
| SL009 | P1 | 总时长预算 | 实际总时长与目标偏差超过 15% |
| SL010 | P1 | 转场合法性 | 连续三个以上叠化；非末尾镜头出现 FADE_OUT |
| SL011 | P2 | 景别节奏 | 连续四个以上同景别，平均单镜超过 3.5s 时升为 P1 |
| SL012 | P2 | 情绪单调 | 连续四个以上镜头情绪相同 |
| SL013 | P2 | 字幕长度 | 单条字幕宽度超过 18 字 |
| SL014 | P2 | 物件闪现 | 同一场景内某角色手上的东西消失又出现 |
| SL015 | P2 | 建置镜头 | 场景首次出现没有给全景 |

## 三条规则的判据说明

这三条是全项目最有价值的，因为它们的判据不是拍脑袋定的，是从实际翻车案例里倒推的。

**SL003 语速。** 上限 7.5 字/秒是配音演员带情绪时的稳定极限，超过必然吞字。下限 2.2 字/秒——一开始定在 3.0，结果误伤了大量正常镜头：一句五个字配两秒的表演节奏是完全合理的，中间有停顿和表演。字数统计中文按字计、英文按词计。

**SL008 越轴。** 判据是：相邻两镜同场景，共同角色不少于两个，且所有共同角色的 `screen_dir` 在 left 与 right 之间整体对调。前一个是 `EXTREME_WIDE` 或 `WIDE` 时不算越轴，因为全景镜头会重设轴线。这条是 AI 分镜最难自检的——模型只看单镜文本，不记得上一镜谁在左边。

**SL011 景别节奏。** 连续四个以上同景别才报，因为正反打本来就是连续特写，三个以内是合法节奏。只有当平均单镜超过 3.5 秒时才升到 P1——快切的同景别序列是风格，长镜头堆同景别才是发闷。

## 规则的实现位置

全部在 `shotlock/rules.py`，每条规则一个函数，签名统一为 `fn(script) -> list[Issue]`。加新规则的流程见 `CONTRIBUTING.md`。
